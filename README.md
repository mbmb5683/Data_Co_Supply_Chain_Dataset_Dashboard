# Data_Co_Supply_Chain_Dataset_Dashboard

An interactive Power BI dashboard built using the DataCo Supply Chain dataset to explore sales, profitability, order, product, market, and customer-related information.

Project Overview

This project presents supply-chain and sales data through a multi-page Power BI report. It is designed to help users explore business performance, identify patterns across products and markets, and review customer-related information using interactive visualizations and filters.

Dashboard Pages

The .pbix report contains four pages:

Supply Chain & Sales Analytics Dashboard

Sales and date-based trend visualization

Category-level analysis

Customer-country distribution

Product, order type, and market slicers

Quantity and category-focused visualizations

Country Sales and Profit Trend Analysis

Country-level geographic analysis

Sales and profit trend reporting

Department-related report view

Customer Dashboard

Customer-focused report page

Tabular and chart-based analysis

Interactive filtering

Review Table

Review-related tabular report view

Slicers for exploring the displayed data

Note: The exact measures, data model relationships, and source-column definitions should be confirmed in Power BI Desktop before being documented in more detail.

Tools & Technologies

Microsoft Power BI Desktop — report development and interactive visualizations

DataCo Supply Chain Dataset — underlying project dataset

Power Query — available in Power BI for data preparation and transformation, if used in the report

How to Open the Dashboard

Download or clone this repository.

Install Microsoft Power BI Desktop.

Open Data_Co_Supply_Chain_Dataset_Dashboard.pbix in Power BI Desktop.

Wait for the report and visuals to load.

Navigate between the four report pages using the page tabs.

Use the available slicers and visual interactions to explore the data.

How to Use

Select values in slicers to filter the report.

Select chart elements to cross-filter or highlight related visuals.

Move between report pages to explore sales, country, customer, and review information.

Use the report's interactive visuals to investigate patterns in the available dataset.

Project Goals

Present supply-chain and sales information in an interactive format.

Explore performance across product categories, countries, markets, and order-related dimensions.

Make customer and review information easier to inspect.

Demonstrate business intelligence reporting and data visualization using Power BI.

Notes

This repository contains the Power BI .pbix report.

The source dataset is not included as a separate file in this repository.

If the report is later connected to an external data source rather than using embedded data, configure the data-source credentials and refresh settings in Power BI Desktop.

Dashboard values and visuals depend on the data contained in the report.
